# foundations pack

**Block 1, weeks 1–4** (`docs/SPEC.md` §4.2, §4.3). Output: a completion record
and a go/no-go decision. Unproctored.

US health-system literacy and self-selection — the layer that lets a trainee
decide whether this work suits them before anyone is assessed on a domain.

| Week | Content                                                                                                              | Output                               |
| ---- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 1    | US healthcare organization: payers, providers, PBMs, TPAs, brokers, regulators; premium → payer → provider → patient | System map exercise; checkpoint quiz |
| 2    | Coverage: commercial, Medicare, MA, Medicaid, exchange; deductible, coinsurance, OOP max, networks                   | Benefits-explanation exercise        |
| 3    | Role families: claims, enrollment, UM, RCM; payer vs provider ops; handoffs                                          | Role-family self-assessment          |
| 4    | Industry pressures; AI and frontline work; the human-in-the-loop role                                                | Block 1 completion; go/no-go         |

Empty until the Foundations content change authors it. Checkpoint quizzes reuse
the MCQ engine in its unproctored, unlimited-attempt configuration (§10), so
this pack carries quiz content, not a quiz engine.

Reporting counts a Block 1 go/no-go exit **separately from a failure** (§34) —
self-selection working as designed is not attrition.
