# compliance pack

**Block 2, weeks 5–6** (`docs/SPEC.md` §4.2, §4.3). Output: the Compliance
Passport, via two proctored exams (§27).

| Week | Content                                                        | Output                                 |
| ---- | -------------------------------------------------------------- | -------------------------------------- |
| 5    | HIPAA privacy & security; documentation discipline             | Proctored Compliance Exam 1            |
| 6    | FWA; security awareness (HITRUST CSF-aligned); code of conduct | Proctored Compliance Exam 2 → Passport |

Empty until the Compliance Passport change authors it.

Three constraints on this pack specifically:

- **Exams are composed from a blueprint**, not hand-picked per cohort (§22), so
  every market and institution sits the same standard. The blueprint lives in
  `pack.json`.
- **Localization cannot alter a proctored assessment**, its pass standard, the
  DRI flow bank or the DRI methodology (§10). One exam bank per pack across all
  markets and institutions.
- **Wording is legally load-bearing.** Copy must say "HITRUST CSF-aligned
  security awareness" and must never imply individual HITRUST certification. A
  guard test asserts that phrase on the Passport template (§43).

A Passport is never issued for viewing content alone (§27).
